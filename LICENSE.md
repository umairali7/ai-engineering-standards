The AI Engineering Standards (AIES) project will finalize its license before
the v1.0 public release, following the process in
[GOVERNANCE.md](GOVERNANCE.md). [ADR-0014](adr/ADR-0014-Dual-License-Standards-and-Software.md)
formally proposes an openly licensed repository: **CC BY-SA 4.0** for standards
and reusable assessment content, and the OSI-approved **Apache 2.0** license for
executable software. The ADR is Proposed, not Accepted, so it does not yet grant
either license.

  selected license applicable to the destination path will apply.
