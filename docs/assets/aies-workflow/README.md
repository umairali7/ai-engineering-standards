## Claim boundary

The Qwen figures come from a retained 147-scenario
Qwen3-Coder-Next-MLX-8bit run. Its automated reviewer was advisory, human
evaluation was optional and not completed, and the asset makes no formal
qualification claim. The repository-audit frame reflects a local self-audit on
2026-08-03: 21 of 26 checks verified, five gaps retained, and the RT2 —
Moderate gate passed. It is self-assessment evidence, not certification.

The assets contain no raw scenario prompts, model responses, endpoints,
machine identifiers, environment fingerprints, or secret material. Recheck
every time-sensitive fact and rerun claim review before using a frame in a new
release, article, talk, or comparison.
